## Vesta — AI coding cost firewall and development workspace

**Role:** Founder / Software Engineer  
**Status:** Private product in active development

Vesta is a cross-platform, local-first workspace for AI-assisted software development. It is designed to reduce unnecessary model spend while making agent execution more transparent, controllable and verifiable.

### Problem

Modern AI coding workflows are often fragmented across desktop applications, terminals, model providers and subscriptions. Developers can lose visibility into model usage, costs, repository state, commands, file changes and the evidence behind an agent's claim that work is complete.

### Engineering approach

- Shared core powering desktop and command-line workflows.
- Cost-aware routing across deterministic tools, local models and cloud providers.
- Token and estimated-cost accounting with execution receipts.
- Streaming activity timelines and cancellable process trees.
- Repository identity checks, permission boundaries and isolated Git worktrees.
- GitHub issue, branch, pull-request and review workflows.
- Safety policies for destructive, irreversible, secret-related and paid actions.
- Evidence-based verification so model prose cannot substitute for test results.

### What it demonstrates

AI agent orchestration, developer-tool architecture, desktop and CLI engineering, GitOps, local-first privacy, safety design, model routing, testing strategy and product ownership.

**Primary stack:** Python, TypeScript, desktop UI, CLI tooling, LLM integrations, Git and GitHub automation.

## QuotePack — product platform for Irish trade businesses

**Role:** Founder / Product Engineer  
**Status:** Private commercial project in active development

QuotePack helps small Irish trade businesses create clearer, faster and more profitable quotes without adopting heavyweight job-management software.

### Product scope

- Browser-based margin and markup calculator.
- Day-rate and hourly-rate calculator.
- VAT calculator.
- Job-profitability checker.
- Materials and labour estimator.
- Deposit and staged-payment calculator.
- Digital quote templates, material checklists and supporting product packs.

### Engineering approach

- Deterministic calculation engines separated from presentation logic.
- Formula matrices and automated QA for financial calculations.
- Accessibility and presentation contracts for core user journeys.
- Privacy-aware browser tools that avoid unnecessary data collection.
- Release gates, decision records and evidence-led product expansion.
- Structured product, legal, tax and operational documentation.

### What it demonstrates

Product discovery, commercial product engineering, deterministic business logic, accessibility, automated QA, conversion-focused UX and end-to-end ownership.

**Primary stack:** Next.js, TypeScript, browser-based calculation engines, automated testing and product documentation.
